// How a mod ships

From idea to live server

  1. Stage 01

    Community idea

    Suggestions and polls in Discord shape what we build next.

  2. Stage 02

    Build

    Written from scratch, configurable through commented JSON.

  3. Stage 03

    Test server

    Shaken down on our test server, with a memory and stability check.

  4. Stage 04

    Live

    Rolled onto MM servers, then to the Steam Workshop when ready.
